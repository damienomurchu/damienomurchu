# Damien Murphy

Engineer working on platforms, software delivery, security, and the systems around them.

I am interested in how engineering systems are built, where their abstractions break down, and what makes them reliable and durable in practice.

My work spans platform engineering, CI/CD, software supply-chain security, developer infrastructure, Kubernetes, AWS, GitHub Actions, and increasingly local and applied AI infrastructure.

A recurring theme in my work is reducing complexity for the people operating inside a system: building sensible defaults, making secure paths easier to follow, and turning repeated engineering effort into reusable capability.

## Engineering Principles

* Prefer paved roads over policy documents
* Reduce cognitive load at system boundaries
* Design for failure, recovery, and operational ownership
* Automate repeated work, but preserve judgement
* Make responsibility and system boundaries explicit
* Turn lessons into reusable systems and documentation

> Build systems that remain useful after the initial problem has been solved.
